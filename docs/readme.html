01

Обзор

Сайт образовательного консультанта — пятистраничный лендинг с админ-панелью, встроенным поиском, чат-ботом, тёмной темой и cookie-баннером. Сделан с нуля: HTML, CSS, JavaScript. Без конструкторов, без фреймворков, без базы данных.

Ключевая идея: вы сами управляете контентом через админ-панель. Я не нужен для рутинных изменений — только для структурных доработок.

📌

Это v1.0. Всё, что описано ниже, — не финальный камень. Любой блок можно переписать, переставить, убрать или добавить. Я жду ваших правок.

04

Возможности

🔍

Поиск по сайту

Открывается по Ctrl/Cmd+K или кнопке в шапке. Ищет по всем страницам и секциям, подсвечивает совпадения, ведёт на нужный блок.

💬

Чат-бот

Сценарный помощник: отвечает на вопросы про услуги, цены, документы, запись. Понимает контекст, помнит имя, ведёт историю диалога. Кнопка «Развернуть» делает панель большой.

🌗

Тёмная тема

Три режима: светлая, тёмная и авто (переключается по системным настройкам устройства). Выбор сохраняется.

🍪

Cookie-баннер

При первом визите — красивая плашка с выбором: принять всё, только необходимое, отказаться. Показывается один раз.

📊

Статистика

В админке — вкладка «Статистика» с подключением GoatCounter: бесплатный, без cookie, GDPR-friendly счётчик.

⚙️

Админ-панель

10 вкладок: главный экран, о себе, направления, услуги, процесс, FAQ, журнал, отзывы, контакты, статистика, файл данных.

07

Ограничения v1.0

⚠️

Честно о том, что пока не работает в полную силу. Это не минусы — это точки роста, которые я закрываю в следующих версиях.

  • Админ-панель без синхронизации. Изменения сохраняются в конкретном браузере. Чтобы перенести на другое устройство — есть кнопка «Скачать / загрузить data.json».
  • Формы не отправляют письма. Заявки сейчас принимаются локально. Подключу Formspree, чтобы заявки приходили на почту.
  • Чат-бот — сценарный. Отвечает по ключевым словам из текстов сайта. Для настоящего AI-бота нужен сервер и API-ключ.
  • Статистика — после подключения GoatCounter. Пока счётчик не активирован, на месте цифр — честная заглушка.
  • Документы — демо-HTML. Финальные PDF от юриста подставлю в раздел «Документы».
08

План развития

  • Синхронизация контента

    Подключение Decap CMS: вы публикуете новости и отзывы из админки, они появляются на сайте у всех посетителей.

  • Рабочие формы

    Formspree: заявки и отзывы приходят на почту. Спам-защита, капча при необходимости.

  • SEO и метаданные

    Заголовки страниц, OG-картинки для соцсетей, микроразметка, sitemap, favicon.

  • AI-бот

    Настоящий ассистент с пониманием свободных вопросов — через OpenAI API или DeepSeek.

  • Личный кабинет

    Если понадобится: расписание занятий, материалы, домашние задания для клиентов.
